## 机房 IP、住宅 IP、双 ISP：三个词的区别决定了你账号能活多久

普通VPS给的IP来自数据中心，Whois 一查就是机房或者云服务商。TikTok、亚马逊、TEMU、Shopee 这些平台的风控系统对这类IP段有长期积累的黑名单，你的机器刚开出来，评分可能就已经偏高了。这不是商家的问题，是这类IP的天然属性。

住宅IP来自 Comcast、AT&T、Frontier、SoftBank、KT、Telstra 这类家庭宽带运营商。平台识别到的是「一个普通家庭用户在上网」，和隔壁邻居家的网络没有区别。跨境电商多店铺防关联、TikTok 起号养号、本地化访问，看中的就是这个属性。

「双 ISP」比普通住宅IP再进一步：IP的 ASN 和 Company 字段**同时**指向运营商。很多数据库判断住宅属性时会交叉比对这两个字段，两边都对得上，被判为住宅的概率更高。只对一个，就容易在 IPinfo 里露馅。

所以真正该做的核验只有一步：机器开出来，把IP丢进 IPinfo 或 IP2Location，看类型字段。显示 **Residential / ISP**，说明是真家宽；显示 **Hosting / Data Center**，就是业内说的「伪家宽」，广告写得多好听都没用，IP属性在数据库里是硬指标。

真家宽有物理代价，这点得认。设备真的部署在居民住宅里，向当地运营商申请家庭光纤，资源天然稀缺，补货周期不固定，静态独享的套餐经常断货。这也是为什么有的商家明确写着「只保证是真实家宽IP，不保证纯净度」，因为共享IP段上用户一多，风险标记就会累积。
